# Glossary

| Term | Meaning |
|---|---|
| **50/50** | An agreed game where each team wins half the altars, for guaranteed tokens |
| **Activity bar** | Anti-idling meter. Empties over time, refilled by using wands or barriers. Empty = kicked |
| **Altar** | The 3 × 3 solid block in the middle of each arena. Also the arena itself ("the Air altar") |
| **Angle** | A standing position plus orb position from which a click sends the orb cleanly into the zone. One of 16 headings ([06](06-angles-and-geometry.md)) |
| **Arch / gap / hole in the pillars** | The one-tile opening between two pillars on each side of the altar, at (0, ±4) and (±4, 0) |
| **Attract / attractor** | The pull wand. Aims an orb up to 2 tiles towards you; reach 10 |
| **Barrier / barrier generator** | A one-tile field that blocks orbs and players. One per player |
| **Bucket** | One of the five slope ranges that decide an orb's heading: `H`, `h`, `X`, `v`, `V` |
| **Control** | Ownership of an orb. The first toucher controls it while it moves. It goes Controlled → Wait1 → Wait2 → Free when left alone |
| **Crasher** | A player who joins a 50/50 game and plays to win |
| **Dead orb** | An orb pushed where nobody can reach it (over water, lava or behind the Air tree). Also, in the code, an orb that has scored and is waiting to respawn (`deadTime`) |
| **Dogleg** | The diagonal-then-straight path of an orb sent on a knight heading |
| **Drag / orb-drag** | Clicking an out-of-reach orb walks you towards it. The attract fires as soon as it is in reach |
| **F2P / P2P** | Free-to-play / pay-to-play (members) |
| **Glitch-repel / repel trick** | Swapping wands mid-hold to get a "pre-attract" step and score from unusual places |
| **Home square** | The tile in the middle of each side of the altar: N (0,2), E (2,0), S (0,−2), W (−2,0) |
| **Knight heading** | A (1,2) or (2,1)-shaped heading |
| **Large / small altar** | Large: Mind and Earth (spawns 7-16 tiles out, lots of walking). Small: Air, Water, Fire, Body |
| **Mini-pillar** | A tile that blocks one diagonal direction through it |
| **Pillar** | Barrier tiles round the altar at (±1, ±4) and (±4, ±1) |
| **Pillar dragging** | Holding an orb that hugs a pillar pulls you towards it, because its next tile is out of sight |
| **Player queue / priority** | The order the server processes players in. Lower index = higher priority for control ties |
| **Prototick** | A one-tick delay between actions: after moving, or on the second tick of a new hold |
| **Relay** | One player pulls an orb into a teammate's angle and the teammate finishes it |
| **Repel / repeller** | The push wand. Aims an orb up to 2 tiles away from you; works on orbs within 7 tiles |
| **Rock** | A tile that blocks movement but not sight (corner rocks, the altar itself, boulders) |
| **Scoring zone** | The 5 × 5 square round the altar centre, corners included. An orb in it has scored |
| **Spawn point** | One of the fixed tiles an orb can appear on (180-520 per altar) |
| **Tap** | A single-tick click. Moves an orb up to 2 tiles and frees you for the next tick |
| **Thaler** | RuneScape's shared minigame currency, also earned in GOP |
| **Tick** | 0.6 s, one server update |
| **Token** | Runecrafting Guild token, the GOP reward currency |
| **Water tile** | Arena edge, river or lava. Blocks players but not orbs |
